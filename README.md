# spec-simple

Write short specs humans will actually read. 

Add this skill to your AI coding agent for creating simple, human-friendly specifications.

Short specs - better projects. Do not over-document. The spec is a living description of the feature, updated as the project develops.

## Install

In your agent's skills directory:

mkdir spec-simple
cp SKILL.md spec-simple

So you end up with

Claude:
`.claude/skills/spec-simple/SKILL.md`

Others:
`.agents/skills/spec-simple/SKILL.md`
